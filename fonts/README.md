# fonts/

`HomemadeApple-Regular.ttf` is the "Homemade Apple" font from Google
Fonts, used by `write_on_image` in `worksheet_synth.py` to simulate
handwritten answers on synthesized worksheet images.

Source: https://fonts.google.com/specimen/Homemade+Apple
