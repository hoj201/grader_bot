# fonts/

`HomemadeApple-Regular.ttf` is the "Homemade Apple" font from Google
Fonts, used by `write_on_image` in `worksheet_synth.py` to simulate
handwritten answers on synthesized worksheet images.

Source: https://fonts.google.com/specimen/Homemade+Apple
License: SIL Open Font License 1.1 (see the specimen page for full
license terms).

`LiberationSerif-Regular.ttf` is a metric-compatible Times New Roman
substitute, used by `markup.py` to write the correct answer onto a
marked-up feedback page in a plain computer font (issue #71) rather than
the handwriting font above.

Source: https://github.com/liberationfonts (Debian package
`fonts-liberation`)
License: SIL Open Font License 1.1
